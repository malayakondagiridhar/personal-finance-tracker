# Contributing

Thanks for contributing to Personal Finance Tracker.

## Workflow

1. Fork or create a feature branch from `main`
2. Keep PRs focused and small
3. Write clear commit messages
4. Open a PR with context, screenshots (if UI), and test notes

## Branch naming

- `feat/<short-name>`
- `fix/<short-name>`
- `docs/<short-name>`
- `chore/<short-name>`

## Pull request checklist

- [ ] Code builds locally
- [ ] Lint passes (`npm run lint`)
- [ ] README/docs updated if behavior changed
- [ ] No secrets in code/config/history

## Coding expectations

- Prefer readable, simple implementations
- Avoid unrelated refactors in the same PR
- Add comments only where logic is non-obvious

## Issues

Please use issue templates for bug reports, feature requests, and engineering tasks.
